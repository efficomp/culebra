culebra.tools.evaluation.Batch class¶

class Batch(trainer: Trainer, decision_manager: DecisionManager, test_fitness_func: FitnessFunction | None = None, results_base_filename: str | None = None, hyperparameters: dict | None = None, num_experiments: int | None = None)¶

Bases: Evaluation

Generate a batch of experiments.

Parameters:

  • trainer (Trainer) – The trainer

  • test_fitness_func (FitnessFunction) – The fitness function used to test. If omitted, the training fitness function will be used. Defaults to None

  • results_base_filename (str) – The base filename to save the results If omitted, _default_results_base_filename is used. Defaults to None

  • hyperparameters (dict) – Hyperparameter values used in this evaluation, optional

  • num_experiments (int) – Number of experiments in the batch. If omitted, _default_num_experiments is used. Defaults to None

Raises:

  • TypeError – If any of the parameters has an incorrect type

  • ValueError – If any of the parameters has an incorrect value
